🔧 第一步：配置数据库连接
  1. 打开 config.js，把里面的 YOUR_PROJECT_ID 和 YOUR_ANON_KEY_HERE 换成真实的值
  2. 去 supabase.com 免费注册，新建项目
  3. 左侧菜单 → Project Settings → API，复制 Project URL 和 anon public key
  4. 粘贴进 config.js 后保存，重新上传到 GitHub，等待几分钟刷新页面
  5. 第一次打开时还需要在 Supabase 的 SQL Editor 里运行 schema.sql 的内容建表
